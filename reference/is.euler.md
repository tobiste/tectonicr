# Check if object is euler.pole

Check if object is euler.pole

## Usage

``` r
is.euler(x)
```

## Arguments

- x:

  Object of class `"data.frame"` containing the Euler poles of plate
  rotations:

  `plate.rot`

  :   Moving plate

  `lat`, `lon`

  :   coordinates of Euler pole

  `angle`

  :   Angle of rotation

  `plate.fix`

  :   Fixed plate

## Value

logical
